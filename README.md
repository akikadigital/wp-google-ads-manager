## WP Google Ads Manager plugin by [Akika Digital](https://akika.digital)

WP Google Ads Manager is a simple Wordpress plugin that allows you to manage Google Ads on your Wordpress site. The plugin allows you to specify the mapped sections on your homepage, category pages category post pages.

After you map out the ad sections and add them onto the plugin's form, the plugin will then generate textareas where you will add the ad units from Google Ad Manager. You can also specify the ads from Google Adsense or any other Ad serving engine you have.
